# CompareCarrosBR

Comparador brasileiro de carros elétricos e híbridos.

## Arquivos
- `index.html`: interface do Modelo 01 / CompareCarrosBR
- `styles.css`: identidade visual branca, verde e amarela
- `db.js`: base estática com 140 modelos
- `logic.js`: seleção, cálculos de TCO e tabela comparativa

Projeto estático pronto para publicação na Vercel.
